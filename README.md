# خرج‌یار — MVP اندروید

یک اپ آفلاین مدیریت هزینه و درآمد با رابط فارسی و واحد تومان.

## قابلیت‌های پیاده‌سازی‌شده

- ثبت **هزینه** و **درآمد**
- واحد پول: تومان
- تاریخ شمسی
- ویرایش و حذف تراکنش‌ها
- دسته، زیرمجموعه و تگ
- دسته‌های پیش‌فرض برای خوراکی، رفت‌وآمد، خانه، تلفن و اینترنت، خرید، روزمره، تفریح، درمان، آموزش، مالی و سایر
- درآمدهای پیش‌فرض:
  - حقوق
  - حقوق هم‌خانه
  - شغل دوم با نام دلخواه
  - شغل سوم با نام دلخواه
  - قرض با نام منبع/شخص
  - سایر منابع با نام دلخواه
- ساخت دسته/زیرمجموعه و تگ سفارشی
- داشبورد ماهانه:
  - درآمد
  - هزینه
  - مانده خالص
  - بودجه ماهانه
  - مقایسه هزینه با ماه قبل
  - بیشترین دسته‌های هزینه
- بخش مقایسه با نمودار ستونی:
  - درآمد در برابر هزینه، ماه‌به‌ماه
  - مقایسه دسته‌ها
  - مقایسه زیرمجموعه‌ها
  - مقایسه تگ‌ها
  - روند ماه‌به‌ماه یک دسته/زیرمجموعه/تگ
  - بازه‌های ۳، ۶ و ۱۲ ماهه
- جستجو و فیلتر تراکنش‌ها
- ذخیره کامل اطلاعات داخل گوشی با SQLite
- بدون حساب کاربری و بدون اینترنت

## فناوری

- Kotlin
- Jetpack Compose
- Material 3
- SQLiteOpenHelper
- Android ICU PersianCalendar

## ساخت پروژه

این پروژه برای Android Studio و JDK 17 آماده شده است.

نسخه‌های پیکربندی‌شده:
- Android Gradle Plugin: 9.2.1
- Gradle: 9.4.1
- Built-in Kotlin / Compose Compiler plugin: 2.3.10
- Compose BOM: 2026.08.00
- compileSdk: 37
- targetSdk: 36
- minSdk: 26

### روش اجرا

1. پوشه پروژه را در Android Studio باز کنید.
2. مطمئن شوید Android SDK API 37 و Build Tools مناسب نصب است.
3. Gradle Sync را اجرا کنید.
4. یک گوشی یا Emulator اندرویدی انتخاب کنید.
5. Run را بزنید.

> فایل `gradle-wrapper.properties` در پروژه قرار دارد. اگر Android Studio درخواست Gradle wrapper JAR کرد، از گزینه Sync/Repair Gradle Wrapper یا Gradle نصب‌شده توسط Android Studio استفاده کنید.

## گام‌های منطقی بعدی

این MVP طوری نوشته شده که بتوان در نسخه بعدی این موارد را اضافه کرد:

- خواندن خودکار پیامک بانکی
- تراکنش‌های تکرارشونده
- اقساط و یادآوری
- خروجی Excel و PDF
- بکاپ ابری
- حساب‌های بانکی مختلف
- درآمد/هزینه مشترک خانوادگی
- قفل PIN یا اثر انگشت
