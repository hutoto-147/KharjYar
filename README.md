# دخل و خرج

**دخل و خرج** یک اپ اندرویدی فارسی برای مدیریت مالی شخصی است؛ با تمرکز روی ثبت سریع درآمد و هزینه، بدهی و قرض، اقساط، یادآورها، گزارش‌گیری و نگه‌داری اطلاعات به‌صورت محلی روی گوشی.

> وضعیت پروژه: نسخه آزمایشی فعال  
> نسخه توسعه: `1.1.0-beta4` — `versionCode 8`

---

## امکانات

### ثبت و مدیریت تراکنش‌ها

- ثبت **هزینه** و **درآمد**
- واحد پول: **تومان**
- تاریخ شمسی
- ویرایش و حذف تراکنش‌ها
- دسته، زیرمجموعه و تگ
- دسته‌ها و تگ‌های سفارشی
- انتخاب حساب و عضو خانواده / هزینه مشترک
- نمایش مبلغ با جداکننده سه‌رقمی هنگام ورود، مثل `۸۰,۰۰۰,۰۰۰`
- تراکنش‌های تکرارشونده هفتگی، ماهانه و سالانه

### بدهی، قرض و اقساط

- ثبت بدهی و قرض
- ثبت مانده فعلی و تاریخ
- نگه‌داری سابقه تغییر مانده
- ثبت اقساط
- تعداد اقساط باقی‌مانده
- تاریخ سررسید
- یادآوری اقساط و تعهدات مالی

### یادآورها

- یادآور عمومی، چک، بدهی، قرض و قسط
- تعیین تاریخ، ساعت و دقیقه
- اعلان با صدای پیش‌فرض دستگاه و لرزش
- امکان بازکردن تنظیمات صدای کانال یادآورها

### داشبورد

- درآمد ماه جاری
- هزینه ماه جاری
- مانده خالص
- بودجه ماهانه
- مقایسه با ماه قبل
- بیشترین دسته‌های هزینه
- جمع بدهی‌ها و قرض‌های فعال

### تراکنش‌ها و مرتب‌سازی

نمایش یکپارچه تراکنش‌ها، بدهی‌ها و قرض‌ها با:

- فیلتر همه / درآمد / هزینه / بدهی / قرض
- مرتب‌سازی بر اساس **تاریخ**
- مرتب‌سازی بر اساس **مبلغ**
- ترتیب صعودی و نزولی

### مقایسه و نمودارها

- درآمد در برابر هزینه
- مقایسه ماه‌ها
- میانگین ۳ ماهه و ۶ ماهه
- مقایسه با دوره مشابه
- دسته‌ها
- زیرمجموعه‌ها
- تگ‌ها
- روند بدهی و قرض
- چند پالت رنگی برای نمودارها

### بکاپ و انتقال اطلاعات

- تهیه بکاپ JSON
- بازیابی بکاپ
- ایجاد **Safety Backup** قبل از Restore
- خروجی Excel (`.xlsx`)
- خروجی PDF
- در Android 10 و بالاتر، خروجی‌ها در مسیر زیر ذخیره می‌شوند:

```text
Downloads/DakhlKharj/
```

بکاپ شامل تراکنش‌ها، حساب‌ها، بدهی‌ها، قرض‌ها، تنظیمات، دسته‌ها، تگ‌ها، تراکنش‌های تکرارشونده، اقساط، یادآورها و داده‌های مرتبط است.

### ورود تراکنش بانکی

دو مسیر برای دریافت اطلاعات بانکی در نظر گرفته شده است:

1. **Notification Access** برای خواندن اعلان‌های بانکی
2. خواندن مستقیم SMS در دستگاه‌ها و نسخه‌های Android سازگار

پیام‌ها داخل خود دستگاه پردازش می‌شوند و قبل از تبدیل‌شدن به تراکنش قابل بررسی هستند.

### امنیت

- قفل PIN
- ذخیره PIN جدید با PBKDF2 و Salt
- پشتیبانی از اثر انگشت / قفل دستگاه
- اطلاعات مالی در SQLite محلی ذخیره می‌شوند
- Android Auto Backup خاموش است

## نصب و به‌روزرسانی APK

اگر نسخه قبلی برنامه روی گوشی نصب است و می‌خواهید اطلاعات آن باقی بماند:

1. نسخه قبلی را **Uninstall نکنید**.
2. APK جدید را مستقیماً روی نسخه موجود نصب کنید.
3. در صورت سازگاری امضای APK، Android آن را به‌صورت **Update** نصب می‌کند.
4. دیتابیس موجود با Migration ارتقا داده می‌شود و نباید پاک شود.

نام نمایشی برنامه به «دخل و خرج» تغییر کرده، اما برای سازگاری با نصب‌های قبلی، شناسه بسته همچنان این مقدار است:

```text
com.example.kharjyar
```

اگر Android برای نصب نسخه جدید درخواست حذف نسخه قبلی کرد، قبل از حذف برنامه از اطلاعات خود بکاپ تهیه کنید.

هدف پروژه این است که داده‌های مالی کاربر تا حد ممکن **روی خود دستگاه** باقی بمانند.

- دسترسی اعلان بانکی و SMS فقط برای قابلیت ورود خودکار تراکنش استفاده می‌شود و باید توسط کاربر فعال شود.
- فایل‌های بکاپ و گزارش فقط با اقدام کاربر ساخته می‌شوند.

## Build با GitHub Actions

Workflow پروژه می‌تواند Unit Test و APK دیباگ را بسازد.

از تب **Actions**، Workflow زیر را اجرا یا نتیجه آخرین Push را بررسی کنید:

```text
Build Dakhl-o-Kharj APK
```

بعد از Build موفق، APK از بخش **Artifacts** با نام زیر قابل دریافت است:

```text
DakhlKharj-APK
```

## Build محلی

پروژه را می‌توان با Android Studio و JDK 17 باز کرد.

مراحل کلی:

1. پروژه را Clone یا دانلود کنید.
2. در Android Studio باز کنید.
3. Android SDK موردنیاز را نصب کنید.
4. Gradle Sync را انجام دهید.
5. روی گوشی یا Emulator اجرا کنید.

GitHub Actions برای Build از Gradle `9.4.1` استفاده می‌کند.
