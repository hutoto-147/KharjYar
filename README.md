# دخل و خرج

**دخل و خرج** یک اپ اندرویدی فارسی برای مدیریت مالی شخصی است: درآمد، هزینه، بدهی، قرض، اقساط، یادآورها، گزارش و بکاپ.

**نسخه عمومی نهایی:** `1.0.0`  
**Application ID:** `io.github.hutoto147.dakhlokharj`

## امکانات اصلی

- ثبت و ویرایش درآمد و هزینه با تاریخ شمسی و واحد تومان
- نمایش سه‌رقمی مبالغ با جداکننده فارسی `٬`
- دسته، زیرمجموعه، تگ، حساب و عضو خانواده
- بدهی، قرض، اقساط و یادآورها
- تراکنش‌های تکرارشونده
- داشبورد و نمودارهای مقایسه
- مرتب‌سازی و فیلتر تراکنش‌ها
- Backup / Restore
- خروجی Excel و PDF
- قفل PIN و اثر انگشت / قفل دستگاه
- حالت روشن و تیره و شخصی‌سازی ظاهر
- ورود اختیاری تراکنش بانکی از طریق **Notification Access**

## حریم خصوصی

اطلاعات مالی اصلی روی دستگاه نگه‌داری می‌شوند. نسخه عمومی 1.0.0 دسترسی مستقیم SMS درخواست نمی‌کند.

## نصب نسخه عمومی برای کاربران نسخه آزمایشی

نسخه‌های آزمایشی قبلی از شناسه `com.example.kharjyar` استفاده می‌کردند. نسخه عمومی از شناسه دائمی جدید استفاده می‌کند، بنابراین یک بار انتقال دستی لازم است:

1. در نسخه آزمایشی **تهیه بکاپ** بزنید.
2. مطمئن شوید فایل JSON در `Downloads/DakhlKharj/` موجود است.
3. نسخه عمومی 1.0.0 را نصب کنید.
4. در نسخه عمومی **بازیابی** را بزنید و همان فایل را انتخاب کنید.
5. پس از اطمینان از انتقال اطلاعات، در صورت تمایل نسخه آزمایشی قدیمی را حذف کنید.

## Build

- Kotlin
- Jetpack Compose / Material 3
- SQLiteOpenHelper
- JDK 17
- compileSdk 37
- targetSdk 36
- minSdk 26
- Gradle 9.4.1

Push و Pull Requestها Unit Test و Debug APK می‌سازند.

برای AAB انتشار Google Play، Workflow دستی `Build Dakhl-o-Kharj 1.0 AAB` به چهار Secret امضا نیاز دارد:

- `ANDROID_KEYSTORE_BASE64`
- `ANDROID_KEYSTORE_PASSWORD`
- `ANDROID_KEY_ALIAS`
- `ANDROID_KEY_PASSWORD`

کلید خصوصی یا رمز عبور نباید داخل Repository commit شود.
